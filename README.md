# CloudHR — SK-06 capstone

Multi-tenant HR analytics data for CloudHR: 200 client organisations, month-end workforce snapshots for 2024–2025, leave, performance reviews, and a four-user security map. Power BI Desktop work (the report pages, the relationships, RLS, and Performance Analyzer) is done by hand from the files in this folder.

The local database uses port **5435** so it can run beside the NorthStar lab on port 5434.

## Load the database

From this directory, with Docker running:

```bash
python scripts/generate_cloudhr.py
docker compose up -d
docker exec -i cloudhr-postgres psql -U postgres -d cloudhr -f /sql/01_create_and_load_cloudhr.sql
docker exec -i cloudhr-postgres psql -U postgres -d cloudhr -f /sql/02_validate_cloudhr.sql
```

`generate_cloudhr.py` uses only the Python standard library. The seed is fixed (`20261119`), so a second run rewrites the same files. If `python` opens the Microsoft Store alias, call the real interpreter instead (Python 3.11 or newer).

Power BI connection: host `localhost`, port `5435`, database `cloudhr`, user `postgres`, password `postgres`. That password is for this container only.

The CSVs are the same data if the PostgreSQL connector is unavailable. Get Data from `data/`, then apply the steps in `powerquery/cloudhr_queries.pq` after the source line. Prefer the database. The M is written against it.

## Build order in Desktop

1. Paste each block in `powerquery/cloudhr_queries.pq` into its own query. Create text parameters `Server` (`localhost:5435`) and `Database` (`cloudhr`) first. Disable load on `Database` and `stg_employee_monthly`.
2. Create the relationships and sort-by columns in `docs/01_data_model_design.md`. Leave the three `dim_employee` relationships **inactive**. Mark `dim_date` as a date table.
3. Paste the measures from `dax/measures.dax`.
4. Check Acme Labs, Year 2025, before you turn RLS on: headcount 84, turnover 7.45, average salary 91,107.63, leave days 708. The full list is in the report blueprint.
5. Build the five pages from `docs/04_report_blueprint.md`. Import `powerbi/CloudHR.theme.json`.
6. Create the Tenant Access role from `dax/rls_tenant_access.dax` and run the tests in the RLS guide.
7. Fill `docs/06_performance_report.md` from Performance Analyzer.
